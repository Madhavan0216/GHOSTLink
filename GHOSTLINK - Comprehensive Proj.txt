### **3. VPN Controller** (vpn_controller.js)
- **Key Generation**: Uses Node.js `crypto` module with X25519 curve
- **Config Directory**: config

#### **Functions**:
| Function | Purpose |
|----------|---------|
| `generateKeyPair()` | Generates mock WireGuard-compatible keys (base64 encoded 32 bytes) |
| `createConfigFile(serverPublicKey, endpoint, clientIp)` | Generates WireGuard config file `wg0.conf` |

#### **Generated Config Format** (`config/wg0.conf`):
```ini
[Interface]
PrivateKey = <base64_private_key>
Address = <clientIp>/32
DNS = 1.1.1.1

[Peer]
PublicKey = <serverPublicKey>
Endpoint = <endpoint>
AllowedIPs = 0.0.0.0/0
PersistentKeepalive = 25
```

---

### **4. Relay Server** (relay_server.js)
- **Port**: 9050 (Standard Tor SOCKS port)
- **Protocol**: Custom "Ghost" binary protocol
- **Purpose**: Acts as a network relay node (Tor-like hop)

#### **Packet Format**:
```
[1 byte: IP Length][N bytes: Target IP][2 bytes: Target Port (Big Endian)][Payload...]
```

#### **Flow**:
1. Receives connection
2. Parses target IP/port from first data packet
3. Forwards data to target
4. Pipes bidirectional data streams

---

### **5. Remote VPN Server** (vpn_server_node.js)
- **Target OS**: Linux (Ubuntu)
- **Interface**: `wg0`
- **Listen Port**: 51820 (WireGuard default)
- **Server IP**: 10.0.0.1/24

#### **Features**:
- Auto-generates server key pair in `/etc/wireguard/`
- Configures NAT masquerading via iptables
- Supports adding peers dynamically

#### **Deployment Requirements** (README.md):
1. VPS with Ubuntu 20.04/22.04
2. WireGuard installed (`apt install wireguard`)
3. Node.js installed
4. Run with `sudo node vpn_server_node.js`

## ⚠️ **Important Observations**

### **Simulation vs Reality**:

| Feature | Implementation | Real Tor/VPN |
|---------|----------------|--------------|
| Circuit Nodes | Hardcoded mock IPs | Directory server with real nodes |
| Handshake | `setTimeout` delays | Diffie-Hellman key exchange |
| Encryption | None (simulated) | Multi-layer encryption |
| Traffic Routing | Not implemented | Actual onion routing |
| Exit Node | Mock IP | Real exit to internet |

### **Code Observations**:

1. **Unused Import**: `net` is imported in server.js but never used
2. **Database Location**: SQLite file created in project root (not config)
3. **Missing npm script**: package.json has `"main": "index.js"` but main file is server.js
4. **Relay Server Standalone**: relay_server.js runs independently on port 9050
5. **VPN Server Linux-only**: vpn_server_node.js requires Linux + WireGuard

### **Potential Improvements**:
1. Add actual cryptographic handshakes
2. Implement real SOCKS5 proxy support
3. Add WebSocket for real-time status updates
4. Store database in config directory
5. Add environment configuration
6. Implement actual circuit-building logic
